# OCLive 插件社区评价索引

为 OCLive 插件保存可审阅的社区评价条目。数据入口是 [reviews.json](reviews.json)，提交方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。

An optional community-review index for OCLive plugins. Reviews are attributable feedback, not compatibility or security certification.

## 当前状态

这是索引格式与贡献入口，当前 `reviews.json` 尚无评价条目。它不托管插件代码，也不提供一个已经运营的评分网站。

评价以 `pluginId` 与 `pubkeyId` 标识对象，并可进一步注明版本。具体字段以索引和贡献说明为准；客户端是否读取、如何显示由接入方决定。

## 使用与贡献

1. 先在 [插件目录](https://github.com/linkaiheng2233-cyber/awesome-oclive-plugins)找到插件的实际来源。
2. 按[贡献说明](CONTRIBUTING.md)提交有上下文、可复核的使用反馈。
3. 通过 PR 保留评价的修改记录；格式问题可开 [Issue](https://github.com/linkaiheng2233-cyber/awesome-oclive-plugin-reviews/issues)。

体验 A.I.Live 请进入[主仓库](https://github.com/linkaiheng2233-cyber/oclivenewnew)。评价不能替代发布者说明、源码核对或目标 Host 的兼容验证。
